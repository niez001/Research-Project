1. System Overview

The system is an assistive technology for learning and memorizing religious texts, designed around accessibility needs. It supports blind students, deaf students, accompanying teachers, and pesantren administrators.

Accessibility

Audio-Tactile

For blind students: audio navigation, rhythmic audio for tikrar, vibration feedback, practice, and memorization submission.

Accessibility

Visual-Spatial

For deaf students: visual text presentation, structural marking/grouping, and spatial mapping to support memorization.

Assessment

ASR + Tajweed NLP

Voice submissions can be transcribed using Automatic Speech Recognition and analyzed through a Rule-Based Tajweed NLP module.

Platforms

Web/PWA + Android

The interface is designed for smartphones, tablets, laptops, and PCs, connected to the backend through HTTPS/REST API.

2. Use Case Diagram

Figure 1. Use Case Diagram

The use case diagram describes interaction between users and the assistive technology system for religious-text memorization. The four main actors are blind students, deaf students, accompanying teachers, and pesantren administrators.

  • Blind students: access learning materials using audio, rhythmic audio, and vibration feedback.
  • Deaf students: use visual-spatial features to understand and memorize text structure.
  • Teachers: monitor activities and provide evaluation.
  • Administrators: manage student and learning-material data.
  • Memorization submission: supported through speech recognition (ASR) and Tajweed analysis.

3. Activity Diagram

Figure 2. Activity Diagram

The activity diagram describes the learning and memorization-practice workflow according to accessibility needs. For blind students, the Audio-Tactile module provides audio navigation, rhythmic audio for tikrar, vibration feedback, and practice/submission processed through ASR and Tajweed analysis.

For deaf students, the Visual-Spatial module provides visual text, structural marking and grouping, and spatial mapping. Both workflows are integrated with the system to record practice results and update memorization progress.

4. Sequence Diagram

Figure 3. Sequence Diagram

The sequence diagram shows interactions among the student, application, backend, Automatic Speech Recognition (ASR) engine, Tajweed NLP module, and database during practice and memorization submission.

The process begins with authentication and selection of learning material. During submission, a voice recording is sent to the backend, processed by ASR into a transcription, and analyzed by the Tajweed NLP module. The results are used to generate evaluation and feedback, update memorization progress, and store activity history in the database.

6. System Architecture

Figure 4. System Architecture

The architecture uses a multi-platform approach with Web/PWA and Android applications as user-interface layers. Both platforms communicate with the backend through HTTPS/REST API.

Client Layer

The system is designed to be device-independent. It can be accessed through Web/PWA on laptops, PCs, or tablet browsers, Android applications on smartphones and tablets, and other devices supporting browser/PWA. Four user groups are supported: blind students, deaf students, accompanying teachers, and pesantren administrators.

Backend Services

  • Authentication Service: login/logout, authentication, user roles, and access rights.
  • Learning Service: books, learning materials, learning sessions, exercises, and tikrar/repetition.
  • Accessibility Service: determines how materials are presented according to user needs.
  • Progress: records learning progress, materials studied, practice frequency, history, memorization achievement, and evaluation results.
  • Assessment Service: handles memorization assessment, including practice and evaluation.
  • ASR Engine: converts the student's speech into text/transcription.
  • Tajweed NLP: analyzes the recognized text using the tajweed rules designed in the system.
  • Data Access Layer: separates application services from the database structure.

Database Layer

The database stores users, books and materials, learning sessions and practice activities, memorization progress, and system logs.
